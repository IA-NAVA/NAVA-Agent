# Security Policy

This repository is public and only contains presentation materials, public documentation, anonymized demo outputs and non-sensitive assets.

Do not publish:

- NAVA source code
- internal engine files
- adapters source files
- routing logic
- memory databases
- logs
- local configuration files
- API keys
- screenshots showing code, PyCharm, private emails or personal data
- client documents or real business data

If sensitive data is accidentally published, it must be removed immediately from the repository history.

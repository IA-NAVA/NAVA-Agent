# Architecture publique de NAVA

Commande naturelle  
→ Analyse de l’intention  
→ Identification du logiciel adapté  
→ Découpage en étapes  
→ Routage vers l’adapter logiciel  
→ Exécution locale sur Windows  
→ Vérification du résultat  
→ Journalisation  
→ Amélioration progressive

Le cœur technique du moteur NAVA reste propriétaire et privé.
